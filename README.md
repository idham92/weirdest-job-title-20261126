# Weirdest Job Title — Blind Judge Showdown

Entry for the make.fun bounty
[u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922](https://make.fun/bounty/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922).

The program writes a single job title — a real-sounding job with one
hilariously specific twist — to `entry.txt`:

> Senior Prompt Archaeologist for a Haunted Legacy Codebase

(57 characters, within the 60-character limit.)

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Requires Node 22 or later. The title is written to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
